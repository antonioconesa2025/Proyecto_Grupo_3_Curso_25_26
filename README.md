##  Descripción

<span class="highlight-title">Comemos Seguros</span> es el proyecto final del grupo para la asignatura de Proyecto Intermodular 1ºDAM. Se trata de una pequeña web de presentación y documentación de un sistema pensado para gestionar alergias, intolerancias y menús seguros en entornos colectivos.

##  Qué incluye el proyecto

- <code class="code-badge">web/ComemosSeguros/</code> — Sitio web principal con la página <code class="code-badge">index.html</code>, imágenes y estilos CSS.
- <code class="code-badge">diagramas/</code> — Planos y diagramas del proyecto, como el modelo E-R, clases y casos de uso.
- <code class="code-badge">Miscellanea/</code> — Documentación complementaria, propuestas, imágenes de marca y entregables.
- <code class="code-badge">Presentación.txt</code> — Información de presentación del proyecto.

## Estructura principal

- <code class="code-badge">web/ComemosSeguros/index.html</code> — Página de presentación del proyecto.
- <code class="code-badge">web/ComemosSeguros/styles/styles.css</code> — Estilos visuales.
- <code class="code-badge">web/ComemosSeguros/img/</code> — Imágenes usadas en la web.
- <code class="code-badge">diagramas/Diagrama_Modelo E-R.png</code> — Modelo entidad-relación.
- <code class="code-badge">diagramas/UseCase_ComemosSeguros.png</code> — Diagrama de casos de uso.

## Cómo ver el proyecto

1. Abre la carpeta <code class="code-badge">web/ComemosSeguros/</code>.
2. Haz doble clic en <code class="code-badge">index.html</code>.
3. Visualiza la web en tu navegador.

## Objetivo del proyecto

Crear un sistema visual y accesible para gestionar:

- alérgenos alimentarios,
- intolerancias,
- planificación de menús,
- protección de usuarios en colegios, hospitales y otros centros.
